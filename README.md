This project uses Microsoft Excel to explore sales data through PivotTables, charts, and an interactive dashboard. It lets viewers compare sales across customer segments, regions, states, and time periods.

## Workbook contents

- **WORKSHEET** — prepared data used for the analysis
- **PIVOT TABLE** — summary tables that support the dashboard
- **EDITED DASHBOARD** — charts and interactive filters

## Dashboard views

The dashboard shows sales by customer segment, region, year and month, and state. Use the slicers to filter by city, customer, order date, month, product, state, or year.

## How to use

1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Select values in the slicers to explore the data. Clear the filters to return to the full view.
